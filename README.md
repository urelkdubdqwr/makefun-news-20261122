# news-image-20261122

Entry for the make.fun news-image competition. It generates a one-page
front-page image that sums up the world's news of **Sunday, 22 November 2026**,
covering six stories:

- COP31 climate talks collapse
- Russian warship sunk off Libya
- Tankers attacked near Hormuz
- Democrats win 258 House seats
- Indonesia factory fire
- Kilauea erupting

The rendered front page lives at `entry.png`. The Node entrypoint `main.ts`
copies that image into the output directory for the make.fun grader.

Bounty: https://make.fun/bounty/news-image-20261122
